# verstehst-mi

# Steirisch ↔ Deutsch Übersetzer

Ein Lernprojekt auf dem NVIDIA Jetson Orin Nano: Übersetzung zwischen
steirischem Dialekt und Hochdeutsch – per Text und Sprache.

## Status

🚧 In Entwicklung

## Geplante Funktionen

- Wörterbuch mit geprüften Einträgen (SQLite)
- Spracherkennung (Whisper)
- Sprachausgabe (Piper)
- Weboberfläche, auch am Handy nutzbar
