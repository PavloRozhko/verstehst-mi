# Крок 5b: критерії й тестовий набір (зафіксовано до запуску)

Час фіксації: 2026-10-13, до написання коду правил.

## Що перевіряємо

Чи допомагають 6 надійних правил вимови (3, 4, 5, 11, 12, 16) перекласти слова,
яких немає у словнику.

Правила зворотні: з діалектного слова роблять можливі слова Hochdeutsch.

| № | Правило (HD → діалект) | Зворотний крок (діалект → HD) |
|---|---|---|
| 3 | -er → -a | кінцеве -a → -er |
| 4 | -en → -n | кінцеве -n після приголосної → -en |
| 5 | -e відпадає | додати -e в кінці |
| 11 | ge- → g- | g + приголосна на початку → ge- |
| 12 | -ch відпадає (ich/mich/dich/sich) | i, mi, di, si → ich, mich, dich, sich |
| 16 | eu/äu → ei | ei → eu або äu |

Правила можна поєднувати (Leit → Leut → Leute: 16 + 5).
Кандидат приймається, лише якщо таке слово є в колонці Hochdeutsch словника.
Інакше правило нічого не пропонує (щоб не вигадувати слів).

## Тестовий набір

Усі 210 фраз, які імпортуються в базу (статус richtig/korrigiert).
Для кожної фрази:

1. `woerter_suchen` (як у KI-перекладі, з derb) знаходить слова;
2. слова, яких не знайдено і які не є словами Hochdeutsch (`hochdeutsch_abtrennen`),
   це «цільові слова»;
3. до кожного цільового слова застосовуються правила.

Щоб відповідь не «підглядала», словник Hochdeutsch для перевірки кандидатів
будується з усіх записів, **крім самої фрази**, яку перевіряємо.

## Як рахуємо

- **richtig**: запропоноване слово є в перевіреному перекладі цієї фрази;
- **nicht bestätigt**: запропоноване слово в перекладі відсутнє
  (або помилка, або переклад ужив синонім; список додається для ручної перевірки);
- **ohne Vorschlag**: правила нічого не дали.

Точність = richtig / (richtig + nicht bestätigt).

## Критерії

- **go**: точність ≥ 90 % і щонайменше 10 слів richtig;
- **no-go**: інакше.
- Обов'язково: слова, які знаходились і без 5b, не змінюються
  (5b працює лише для слів, яких не знайдено).

Порогів після запуску не змінюємо.
